A SHORT LESSON

Your first variable in C

A variable stores information that a program can use. In this example, we store a name and show a greeting on the screen.

Example: a simple greeting

Goal: save a name and print a message.

#include <stdio.h>

int main() {
    char name[] = "Alex";

    printf("Hello, %s!\\n", name);

    return 0;
}

How does it work?

1. char name[] creates a variable to store text.
2. "Alex" is the value saved in the variable.
3. printf() shows the message. The symbol %s is replaced by the text in name.

Expected result:

Hello, Alex!

Common beginner mistake: forgetting the quotation marks around the text. Text values need quotation marks in this example.
